helpful, so I've decided to rewrite them in Rust, making them usable outside of Emacs.

进程调用栈分析工具

Usage: cs [OPTIONS] [FILES]...

Arguments:
  [FILES]...  读取调用栈的文件，使用 "-" 表示标准输入；多个文件会被合并

Options:
  -p, --pid <PIDS>               显示指定 PID 进程的调用栈
      --parent <PARENT>          显示父进程 PARENT 的所有子进程的调用栈
  -c, --core <CORE>              显示 coredump 文件中的调用栈
  -e, --executable <EXECUTABLE>  (可选) 产生 coredump 的可执行文件
  -u, --users <USERS>            列出或选择指定用户的进程（多个用户用逗号分隔）
  -i, --initial <INITIAL>        进程过滤的初始值
  -l, --list                     列出进程
  -t, --interval <INTERVAL>      采样间隔（秒），不应小于 0.1 秒。
                                 仅在获取运行中进程的调用栈时适用。
  -n, --count <COUNT>            采样次数。
                                 仅在获取运行中进程的调用栈时适用，且需指定 `interval`。 [default: 1]
  -F, --frames <FRAMES>          获取调用栈的帧数，0 表示不限制 [default: 2048]
  -j, --json                     以 JSON 格式输出堆栈信息
  -m, --match <MATCH_MODE>       堆栈去重时的匹配模式：precise（按完整帧信息去重）或 fuzzy（仅按函数名去重）。
                                 默认 auto：单进程用 precise，多进程/文件/diff 用 fuzzy。 [possible values: precise, fuzzy]
  -E, --exclude <EXCLUDE>        排除匹配指定正则的堆栈（可重复使用，匹配帧的 function 字段）
  -f, --format <FORMAT>          输出格式：text 或 json（优先于 --json） [possible values: text, json]
  -v, --verbose                  显示完整输出（不截断）
      --diff <BEFORE> <AFTER>    对比两个 JSON 格式的堆栈快照文件
      --diff-live                仅采样两次（before + after）并输出 diff。
                                 配合 -t 可指定间隔秒数，不带 -t 则等待按回车触发第二次。
  -W, --Wide                     宽模式：显示进程时显示所有字符
  -M, --multi                    多选模式：选择进程时支持多选
  -U, --unique                   去重模式：显示调用栈时合并相同栈
  -G, --gdb                      使用 gdb 获取调用栈（默认使用 eu-stack）
  -R, --raw                      原始模式：不对调用栈做简化（仅与 -G 配合使用）
  -N, --no-pager                 禁用分页器
  -P, --pattern <PATTERN>        显示名称匹配 PATTERN 的进程的调用栈
  -h, --help                     Print help (see more with '--help')
  -V, --version                  Print version

基本示例:
  - `cs --help`:                        显示本帮助信息
  - `cs`:                               交互式选择进程并显示调用栈
  - `cs -M`:                            交互式选择多个进程并显示调用栈
  - `cs -p 905`:                        显示进程 905 的调用栈
  - `cs -p 905 -U`:                     显示进程 905 的去重调用栈
  - `cs -U -P google.chrome`:           显示所有 Chrome 进程的去重调用栈

进阶示例:
  - `cs -U -p 905 -t 0.5 -n 3`:         进程 905 采样 3 次（间隔 0.5 秒），去重输出
  - `cs -p 905 --json > snap.json`:     保存进程 905 的快照为 JSON
  - `cs --diff before.json after.json`:	对比两个 JSON 快照文件
  - `cs --diff-live -p 905 -t 2`:       直接采样两次（间隔 2 秒）并输出 diff
  - `cs --diff-live -p 905`:            按回车触发第二次采样，输出 diff
#+end_example
